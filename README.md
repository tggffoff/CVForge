# CVForge

CVForge est un générateur de CV moderne, simple et gratuit.

Il permet de créer un CV directement depuis son navigateur, sans compte et sans serveur.

## ✨ Fonctionnalités

- 📝 Modification du CV en temps réel
- 👤 Informations personnelles
- 💼 Ajout de plusieurs expériences professionnelles
- 🎓 Ajout de plusieurs formations
- 🛠️ Gestion des compétences
- 🎨 Plusieurs couleurs d'accent
- 💾 Sauvegarde automatique dans le navigateur
- 📄 Export du CV en PDF
- 📱 Design responsive
- 🔒 Aucune donnée envoyée sur un serveur
- ⚡ Aucune dépendance externe

## 🚀 Utilisation

Téléchargez le projet puis ouvrez simplement :

`index.html`

dans votre navigateur.

Aucune installation n'est nécessaire.
